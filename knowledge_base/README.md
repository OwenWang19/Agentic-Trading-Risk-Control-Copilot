# Synthetic Trading Risk Knowledge Base

Every document in this directory is fictional and was created only for software demonstrations, retrieval evaluation, and interviews. Nothing here represents Bitget policy, another exchange's internal policy, legal advice, or production control guidance.

Indexed documents use YAML-like front matter with stable IDs, versions, effective dates, status, jurisdiction, and risk-domain metadata. The RAG pipeline excludes files without a `document_id`, so this README is not indexed.
